# MEP Room Equipment Placement - Minimal Example
# Room: 10m x 8m (10000mm x 8000mm in microns for compatibility)
#
# This is a minimal MEP room that runs out-of-box with AlphaChip.
# Equipment modeled as soft macros (Grp_*), entry points as ports.
# Connections (pipes/ducts) modeled as nets - will minimize total length.
#
# LIMITATIONS (not modeled):
# - Per-side clearances (not supported)
# - Access paths (not supported)
# - Route feasibility check (only optimizes length)
# - Non-rectangular rooms (use blockages as workaround)

# ============================================================
# PORTS - Room entry points (fixed on walls)
# ============================================================
